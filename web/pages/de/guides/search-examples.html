Wenn eine Suche leer bleibt

  • Lesen Sie die Zeile über der Liste: Sie sagt, wie der Satz gelesen wurde. Wurde ein Wort als Ort genommen, schreiben Sie den Ort anders, etwa mit seinem amtlichen Namen.
  • Versuchen Sie eine Lesart oder einen Ort aus den Knöpfen unter dieser Zeile.
  • Nehmen Sie ein gängigeres Wort für die Art von Ort.
  • Zoomen Sie hinaus oder verschieben Sie die Karte. Nennt eine Suche nur eine Art von Ort, sucht sie im Bild.

Schicken Sie uns eine Suche, die gehen sollte, mit Feedback im Menü.
